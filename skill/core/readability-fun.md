# 可读性 & 趣味性：可测项与操作配方

这两项是用户明确指定的重点。它们的难点在于**容易变成形容词自夸**（"更生动了""更有趣了"）。
本文件把它们压成**可数量化**的结构，并把「谁来做」分清：引擎只测和验，模型只做加法。

---

## 一、引擎测什么（`fun_score` 0–100）

趣味性**不用词表**，因为词表只会奖励我写进去的那几个词。改用四种可数结构：

| 维度 | 定义 | 权重 | 实测参照 |
|---|---|---|---|
| 悬念句 `hook_per_para` | 段落 ≥2 句且**末句 ≤18 字** | 25 | 好科普 0.3–0.5；例子一 0.0 |
| 提问 `qmark_per_k` | 问号/千字 | 20 | 例子二 2.08；例子一 0.0 |
| 具体锚点 `anchor_per_k` | 年份/带单位数字/大写专名/引号内具体说法 | 30 | 全文 8.0；好科普 12+ |
| 对话感 `dialogue_per_k` | 第二人称「你」/千字 | 25 | 例子二 9.7；例子一 0.0 |
| 罚项 | 情绪词每千字超 3 起扣，最高扣 25 | – | 白洞段 11.1 |

**这四项全部为 0 的文本，就是真的没有任何读下去的理由**——例子一正是如此（无提问、无数字、无第二人称、结尾是全篇最长的定语从句）。

## 二、引擎测什么（`read_score` 0–100）

| 维度 | 定义 | 权重 |
|---|---|---|
| 跟随词 + 因果连接 | `也就是说/换句话说` + `所以/但是/其实` 每千字 | 35 |
| 句长可控 | 平均句长 ≤ 55 字线性计分 | 35 |
| 换气短句 | 句长变异（超过 0.12 起计） | 20 |
| 悬念句 | 同上 | 10 |

## 三、断言强度 `assert_strength`（rig 模式核心）

```
assert = 绝对化/千字 × 3 + 情绪词/千字 × 2 − 限定语/千字 × 0.4
```

限定语**必须是结构**（`条件下 / 假设 / 近似 / 范围内 / 目前 / 理论上 / 取决于`），
不能是「在」这种虚词——第 1 版的 `qualifier_per_k` 因把「在」算进去而虚高，已剔除。

## 四、操作配方（模型来做，引擎只验）

引擎的正则控件**改不出趣味性**——实测：`cf,unv` 在全文上让趣味分 26→26、可读分 52→52。
原因很简单：删除不创造内容。所以趣味性的四个维度各配一个**加法配方**：

### 1. 悬念句（hook）
在段落**第一句陈述之后**插入一句 ≤18 字的问题或反转。

> 原：模型预测在低负载情况下，扩散过程主要由质子射击噪声驱动。
> 加：**这句话为什么重要？** 因为它把"质子是一个一个来，还是成批来"变成了可测量的量。

### 2. 提问（question）
把定义句改成问句。引擎的 `qst` 控件只认「所谓X是指…」这一种句式，
实测全文 0 命中——**所以提问必须由模型写**。

> 原：所谓质子动力力，是指……
> 改：**细菌的鞭毛靠什么转起来？** 答案是质子动力力：……

### 3. 具体锚点（anchor）
把模糊量词换成可查的数字、年份、专名。**只能加查得到的**，查不到就写「尚无确切统计」。

### 4. 对话感（dialogue）
把「人们认为 / 众所周知」改成「你可能会想」，并把**反方**摆出来。
引擎的 `dlg` 控件做这一层替换，但实测原文没有这些词，同样 0 命中。

## 五、验收：看增量，不看绝对分

`diff_report(before, after)` + `upgrade_ok(rows, mode)`。达标条件：

**rig 模式**
- `assert_strength` 下降，或降到 ≤ 8
- 情绪词 ≤ 3/千字
- 破折号 = 0

**pop 模式**
- 跟随词或连接词至少一项上升
- 平均句长 ≤ 45
- 术语密度 ≤ 40/千字

**两模式共有**
- `fun_score` 不得下降
- `read_score` 不得下降

## 六、已记录的失败（5 轮自优化里真实发生的）

1. **词表陷阱**：第 1 版用「比如/想象/你可以」测趣味性，全文 0 命中、趣味分卡在 30。
   → 改成结构计数。
2. **一票否决**：第 2 版悬念句定义要求「末句 ≤12 字」，例子一判 0。
   → 放宽到 18 字 + 四档梯度 `_grad()`。
3. **标题破折号误伤**：全文 [1] 段「目标设定——AI工具探索——…」12 个破折号是标题分隔线，
   `cf` 会把它改成句号毁掉标题。→ `dashes()` 与 `c_dash()` 都加了「多段且每段 ≤14 字」的标题识别。
4. **加法控件空转**：`dlg/qst` 在真实样本上 0 命中。
   → 结论：趣味性是模型的工作，引擎的职责是**测出来、验达标**，不是假装能自动生成。
