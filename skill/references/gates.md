# 阈值与实测来源

所有阈值都来自实测，不是在论文里抄的。改阈值前请先跑 `python3 core/zh_sci_lens.py selftest`。

## 模式判定

```
hard   = max(0,(mean_len-45))/45*40 + max(0,(0.20-sd))/0.20*25
       + max(0,(defs-2))/10*15 + (conn_per_k<5)*10 + term 项
shallow= max(0,(sensational-3))/15*40 + max(0,(absolute-2))/10*20
       + max(0,(dash-1.5))/5*15 + max(0,(mean_len-40))*0.3 + min(quant,10)*1.5
```

`hard > shallow` → `pop`；否则 `rig`。

## 实测对照（同一位作者的两类样本）

| 指标 | 好科普段落 | 教材体段落 | 白洞狂文 |
|---|---|---|---|
| 句长 cv | 0.33 | 0.15 | 0.13 |
| 连接词/千字 | 14.6 | 0.0 | 0.0 |
| 术语/千字 | 14.6 | 87.4 | — |
| 引号/冒号 | 2 | 0 | 0 |
| tell score | 0.0 | 67.9 | 38.3 |

**关键：好科普段落 tell 也是 0.0。** 所以不能用 tell 区分“难懂”。

## 闸门（`check_gates`）

| 项 | 阈值 | 依据 |
|---|---|---|
| 破折号 | 0 | `deai-pipeline/references/zh-track.md` 的 R 轮闸门 |
| 平均句长 | ≤ 45 字 | 教材体实测 > 60；好科普 25–35 |
| 句长变异 | ≥ 0.20 | 教材体 0.15 |
| AI 词 | ≤ 2/千字 | 好样本 0，AI 样本 81.9 分对应 > 8/千字 |
| 连接词 | ≥ 5/千字（仅 pop） | 教材体 0 |
| 排比 | ≤ 1 处/篇 | 沿用 deai-pipeline |

## 已知失效

- **单句段落 cv = 0.00**：只有一句话时变异无意义，`selftest` 与 `analyze` 都会给出 0。
  判断时必须看 `sents >= 3`。
- **单字被当句**：`1.` 这种编号会让 cv 冲到 0.68（实测伪学术段）。
  引擎已过滤长度 ≤ 1 的片段，但 `apply num` 之前仍应确认。
- **术语表需外部提供**：`--terms` 未实现自动抽取。pop 模式必须先由模型或用户给出术语表，
  否则 `term_per_k` 为 `null`，`hard` 分少了 30 分权重。
